# Python Pizza Order

A command-line application built with Python to calculate the final cost of a pizza order based on pizza size, pepperoni selection, and extra cheese.

## Overview

This project is part of my Python learning journey and focuses on implementing conditional logic and basic calculations to determine the total cost of an order.

The application collects the customer's preferred pizza size, asks whether pepperoni and extra cheese should be added, and calculates the final bill based on the selected options.

## Features

* Calculate pizza prices based on size.
* Add pepperoni at a price determined by the pizza size.
* Include an additional charge for extra cheese.
* Calculate and display the final bill through a command-line interface.

## Technologies

* **Language:** Python 3
* **Interface:** Command-line (CLI)

## Getting Started

### Prerequisites

* Python 3 installed on your system.

### Installation

Clone the repository:

```bash
git clone https://github.com/gabrielbuhendwa/python-pizza-order.git
```

Navigate to the project directory:

```bash
cd python-pizza-order
```

### Running the Application

Execute the main Python file:

```bash
python main.py
```

Depending on your system configuration, you may need to use `python3 main.py` instead.
